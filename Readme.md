#  MySQL  
This repository contains SQL lab exercises, projects, lecture materials and notes related to **CSE208 - Database System**.

Course Information

## Setup Instructions

1. Install [XAMPP](https://www.apachefriends.org/download.html)
2. Start *Apache* & *MySQL*
3. Go to `http://localhost/phpmyadmin/` on your browser


To install XAMPP, watch the following video:  
**[How to install XAMPP on Windows](https://youtu.be/UjAbsItMPRY)**
